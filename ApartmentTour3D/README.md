# סיור תלת־ממדי בדירה — כלניות 17, טירת הכרמל · טיפוס C

אפליקציית סיור אינטראקטיבי בדירה, שנבנתה **מתוך תכנית ה־PDF המקורית** בקנה מידה 1:50.
כל מידה במודל נגזרה מהגאומטריה הווקטורית של התכנית ועוגנה בקווי המידה שלה — לא נמדדה בעין
ולא הומצאה.

```
npm install
npm run dev      # http://localhost:5173
```

## מאיפה הגיעו הנתונים

התכנית היא ייצוא וקטורי מ־CAD, ולכן אפשר לקרוא ממנה מידות אמיתיות ולא לנחש מרסטר.
שני דברים הפכו את החילוץ לאמין:

**1. קנה המידה אומת מול התכנית עצמה.** נקודת PDF אחת = `25.4/72/10 × 50 = 1.76389` ס"מ.
מדידת קווי המידה הכחולים מול המספרים הכתובים לידם:

| כתוב בתכנית | נמדד מהוקטורים |
|---|---|
| 1377 | 1376.7 |
| 1121 | 1120.6 |
| 1016 | 1016.0 |
| 738 | 738.1 |
| 642 | 641.8 |
| 447 | 447.0 |
| 438 | 438.3 |
| 318 | 318.0 |

**2. כל מערכת מצוירת בצבע קו קבוע**, וההפרדה בין השכבות ודאית:

| צבע | שכבה | גיליון |
|---|---|---|
| שחור | אדריכלות — קירות, פתחים, קשתות פתיחה | כולם |
| אפור | ריהוט וכלים סניטריים | כולם |
| כחול | שרשראות מידות | 1 |
| אדום | חשמל | 2, 5 |
| כתום | מים חמים/קרים וגז | 3, 5 |
| ירוק | ניקוז 2" | כולם |
| תכלת | מיזוג אוויר | 4 |

שכבת האדריכלות זהה בייטים בכל ששת הגיליונות, ולכן כל המערכות נרשמות למערכת צירים אחת
ללא שום עבודת התאמה.

### הקישור בין מתג לגוף תאורה

לא נבנה כאן ניחוש: התכנית כותבת ליד כל אביזר את **קוד המעגל** שלו (`13/1`, `17/1`, `10/5`).
מתג וגוף תאורה שנושאים את אותו קוד יושבים על אותו מעגל. הצינור מקבץ לפי הקוד ומייצר את
המיפוי, ומעגל שיש לו יותר ממתג אחד מסומן כמפסק מחליף ומתנהג ככזה.

מעגל תאורה שנמצאו לו גופים אך לא נמצא לו מתג בתכנית מקבל מתג משוער ליד משקוף החדר,
מסומן `inferred` בנתונים ומוצג בממשק כ"השלמה".

## בנייה מחדש של הנתונים

```
pip install -r tools/requirements.txt
python tools/build_apartment_json.py     # מייצר data/apartment.json
python tools/verify_source.py --preview  # בדיקת מידות + ציור המודל מעל התכנית
python tools/verify_source.py --model    # ציור האביזרים והצנרת מעל התכנית
python tools/plan_preview.py --walls --openings --mask
```

`verify_source.py` מריץ 21 בדיקות מול המידות הכתובות בתכנית ונכשל אם מידה כלשהי סוטה
ביותר מ־2 ס"מ. הפלט הגרפי נשמר תחת `public/plan/`.

## מה חשוב לדעת על הדיוק

* **הריהוט הוא להמחשה בלבד.** כך כתוב בתכנית: "סימון אביזרי ריהוט, כלים סניטרים וכדומה
  הינו להמחשה בלבד." כל ממצא בבדיקת התכנון שמערב רהיט מסומן ככזה במפורש.
* **כיוון הצפון אינו מופיע** בגיליונות שסופקו, ולכן הוא נתון לשליטת המשתמש בסרגל.
* **מפלס המסתור** נקרא מהתכנית כ־`+8.01`, כלומר 60 ס"מ מתחת למפלס הדירה. המספר קריא
  בתכנית, אך שווה אימות מול היזם.
* **הקו המקווקו בסימון המעגל הוא קישור לוגי ולא תוואי חיווט.** התכנית אינה מסמנת תוואי
  כבלים, ולכן אין לו על מה להתבסס. הממשק אומר זאת במפורש.
* הטקסט העברי ב־PDF מקודד בפונטים עם מיפוי שבור, ולכן שמות החדרים נקראו מהרסטר ונרשמו
  ידנית. **המספרים** (מידות, גבהי התקנה, קודי מעגלים) מתחלצים נכון ואוטומטית.
