# סכמת `data/apartment.json`

הקובץ נוצר על ידי `tools/build_apartment_json.py`. **אין לערוך אותו ידנית** — מקור האמת
הוא `data/plan-source.json` (קירות, פתחים, חדרים) ו־`data/furniture.json` (ריהוט), יחד עם
החילוץ האוטומטי מה־PDF.

## מערכת צירים

מטרים. `X` ימינה ו־`Z` דרומה — בדיוק כמו במבט־על על התכנית — ו־`Y` כלפי מעלה.
ראשית הצירים היא פינת צפון־מערב של מעטפת הדירה כולל המרפסת, כלומר `(5.751, 3.056)`
במרחב התכנית המקורי.

מפלס הייחוס הוא `+8.61` (מפלס הדירה) והוא `y = 0`. שאר המפלסים יחסית אליו.

## מפתחות עליונים

| מפתח | תוכן |
|---|---|
| `meta` | פרטי הפרויקט, קנה המידה, ופרטי החילוץ (`pt_to_cm`, זמן היצירה, הסקריפט) |
| `levels` | חמשת המפלסים: `main`, `mamad`, `wet`, `sun_balcony`, `service_balcony` |
| `ceilings` | `structural_m` 2.80, `dropped_m` 2.55, `parapet_m` 1.05 |
| `walls` | קירות עם `start`/`end` (ציר הקיר), `thickness`, `height`, ורשימת מזהי הפתחים |
| `openings` | דלתות וחלונות עם `offset` לאורך הקיר, `width`, `sill`, `height`, וכיוון פתיחה |
| `rooms` | מצולע, שטח, מפלס, סוג וגובה תקרה |
| `devices` | אביזרי חשמל ותקשורת עם `circuit`, `height_cm`, `facing` ו־`wall` |
| `circuits` | מעגלים: `switches`, `loads`, `sockets`, `mode` (`single` / `two_way`) |
| `piping` | קווי מים, ניקוז ומיזוג כפוליליינים עם רדיוס |
| `furniture` | ריהוט להמחשה, עם `size` ו־`rotation` |
| `dimensions` | המידות הכתובות בתכנית, עם הקואורדינטות שהן נמדדו ביניהן |
| `notes_he` | הערות המתכנן, כלשונן |

## שדות שכדאי להכיר

### `walls[].axis`
`'h'` לקיר אופקי (Z קבוע), `'v'` לקיר אנכי (X קבוע). התכנית כולה אורתוגונלית.

### `walls[].type`
`concrete_ext` · `concrete_mamad` · `block` · `gypsum` · `parapet` · `louver_screen`.
מחיצות הגבס מזוהות בתכנית בכך שאינן מוצללות בקווי 45° כמו קירות הבטון והבנייה.

### `openings[].hinge` / `toward` / `max_deg`
`hinge` הוא הקצה שבו נמצאים הצירים (`start` או `end` ביחס לכיוון הקיר), `toward` הוא
`1+` או `1-` בכיוון הניצב לקיר, ו־`max_deg` זווית הפתיחה המרבית. שלושת אלה נקבעו לפי
קשתות הפתיחה שבתכנית.

### `devices[].circuit`
קוד המעגל כפי שכתוב בתכנית, בצורה `NN/M`. זהו המפתח שמקשר בין מתג לגוף תאורה.
`null` כאשר לא נמצא קוד ליד הסמל.

### `devices[].inferred`
`true` כאשר האביזר הושלם על ידינו ואינו מסומן בתכנית — קורה כשלמעגל תאורה נמצאו גופים
אך לא נמצא מתג. הממשק מציג אביזרים כאלה עם הכיתוב "השלמה".

### `devices[].facing`
וקטור `[x, z]` על מישור הרצפה, הכיוון שאליו פונה האביזר מפני הקיר. משמש גם למיקום
"הירידה בקיר" שנראית במצב הרנטגן.

### `rooms[].part_of`
המטבח הוא תת־אזור של חדר הדיור: הוא חולק איתו רצפה אך יש לו תקרה מונמכת משלו.

## אימות

```
python tools/verify_source.py            # 21 בדיקות מול המידות הכתובות בתכנית
python tools/verify_source.py --preview  # + ציור המודל מעל שכבות התכנית
python tools/verify_source.py --model    # + ציור האביזרים והצנרת מעל התכנית
```
